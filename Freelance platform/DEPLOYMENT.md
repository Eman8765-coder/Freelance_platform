# Deployment Guide — FreelancePlatform

## System Requirements
- OS: Windows 10 or Windows 11
- Runtime: .NET 8.0 Windows Desktop Runtime
- Storage: 500 MB free space

## Installation Steps
1. Install .NET 8.0 from https://dotnet.microsoft.com/download
2. Extract the ZIP file to any folder (preferably C:\FreelancePlatform)
3. Run Freelance platform.exe
4. Database is created automatically on first run — no setup needed
